Get Firebase Token

  1. Open http://localhost:5173/student/dashboard in Chrome
  2. Press F12 → Application tab
  3. Left sidebar → Storage → Local Storage → http://localhost:5173
  4. Find row with key firebase-auth-token
  5. Click it → look at the Value column (long string starting with eyJ)
  6. Right-click the value → Copy

Then paste it into the terminal prompt and press Enter.

Your token will appear here
